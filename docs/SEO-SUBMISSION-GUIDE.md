# SEO Submission & Organic Indeksering Guide

Dette dokument beskriver hvordan du får AIBooking.dk blogsider indekseret organisk i søgemaskiner og øger synligheden.

## 1. Submit til Søgemaskiner (VIGTIGT - GØR DETTE FØRST!)

### Google Search Console
**Prioritet: HØJEST**

1. Gå til [Google Search Console](https://search.google.com/search-console)
2. Tilføj din website: `https://www.aibooking.dk`
3. Verificer ejerskab (via DNS eller HTML fil)
4. Submit sitemap:
   - Gå til "Sitemaps" i menuen
   - Tilføj: `https://www.aibooking.dk/sitemap.xml`
   - Klik "Submit"
5. Anmod om indeksering af vigtige sider:
   - Gå til "URL Inspection"
   - Indtast hver blog URL og klik "Request Indexing"
   - Prioriter disse URL'er:
     - `https://www.aibooking.dk/blog`
     - `https://www.aibooking.dk/blog/hvordan-ai-widgets-transformerer-kundeservice`
     - `https://www.aibooking.dk/blog/roi-ai-automatisering-virksomheder`
     - `https://www.aibooking.dk/blog/komplet-ai-automatisering-widget-telefon-booking`

### Bing Webmaster Tools
**Prioritet: HØJ**

1. Gå til [Bing Webmaster Tools](https://www.bing.com/webmasters)
2. Tilføj site: `https://www.aibooking.dk`
3. Verificer ejerskab
4. Submit sitemap: `https://www.aibooking.dk/sitemap.xml`

### Yandex Webmaster
**Prioritet: MEDIUM**

3. Submit sitemap

## 9. Content Optimization

### On-Page SEO Checklist
**Prioritet: HØJEST**

For hver blog artikel, verificer:
- ✅ Unik, beskrivende titel (50-60 tegn)
- ✅ Meta beskrivelse (150-160 tegn)
- ✅ H1 tag (kun én per side)
- ✅ H2-H4 struktur
- ✅ Alt text på alle billeder
- ✅ Internal links til andre blog posts
- ✅ External links til autoritative kilder
- ✅ Schema markup (allerede implementeret)
- ✅ Mobile-friendly (allerede implementeret)
- ✅ Fast loading (test med PageSpeed Insights)

### Keyword Optimization
**Prioritet: HØJ**

Primære keywords til target:
- "AI booking system"

- "AI receptionist"

## Vigtige Noter

1. **Konsistens er nøglen** - SEO er en langsom proces. Forvent resultater efter 3-6 måneder.

2. **Kvalitet over kvantitet** - Få få high-quality backlinks er bedre end mange low-quality.

3. **White hat kun** - Undgå:
   - Køb af links
   - Link schemes
   - Keyword stuffing
   - Duplicate content
   - Cloaking

4. **Mobile-first** - 70%+ af trafik er mobil, så test altid på mobile.

5. **User experience** - Google prioriterer sites med god UX:
   - Fast loading
   - Mobile-friendly
   - Secure (HTTPS)
   - Low bounce rate
   - High time on site
